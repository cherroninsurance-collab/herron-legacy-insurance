## Setting your Instagram "link in bio"

Once this branch is deployed, the hub page is live at:

```
https://herronlegacyinsurance.com/social/link-in-bio.html
```

Paste that as your Instagram bio link. Instagram link clicks don't care about URL length.

**Optional — a prettier URL** (`/link`): this needs one line added to your existing `_redirects` file. I did **not** touch that file (you asked me not to). If you want it, add:

```
/link    /social/link-in-bio.html    200
```

Then your bio link becomes `herronlegacyinsurance.com/link`.

> Facebook & Threads captions allow clickable links — drop the full URL inline there.
> Instagram/TikTok captions don't — end with "link in bio 👆" and pin a comment with the link.
